# Лабораторна робота 4: Доменна модель: сутності, інваріанти, інкапсуляція

Цей проєкт демонструє створення захищеної доменної моделі на C#. Використано інкапсуляцію стану (приватні поля, `private set`, колекції `IReadOnlyList`), статичні фабричні методи замість публічних конструкторів та перевірку бізнес-правил (інваріантів) із генерацією відповідних винятків.

## Предметна область
Проєкт розширює предметну область **Замовлення** (`Order`).
- **DTO (`OrderDto`, `CustomerDto`):** Залишилися з попередньої лабораторної роботи як формати для передачі та імпорту даних з CSV/JSON. Вони не містять бізнес-логіки.
- **Доменні сутності (`Order`, `OrderLine`):** Повноцінні класи з поведінкою. `Order` виступає як агрегат, що містить захищену колекцію рядків замовлення (`OrderLine`). Стан замовлення контролюється через перелічування `OrderStatus` (Draft, Confirmed, Cancelled). Мапінг між DTO та сутностями відбувається через спеціальні методи `ToDto()` та `FromDto()`.

## Перелік інваріантів доменної моделі
Сутності гарантують коректність свого стану. Реалізовано такі правила:
1. **Ідентифікатор замовлення** не може бути порожнім (`ArgumentException`).
2. **Назва товару** в рядку замовлення не може бути порожньою (`ArgumentException`).
3. **Ціна товару** не може бути від'ємною (`ArgumentOutOfRangeException`).
4. **Кількість товару** має бути більшою за нуль (`ArgumentOutOfRangeException`).
5. Не можна **додавати нові рядки**, якщо замовлення вже не в статусі чернетки (`Draft`) (`InvalidOperationException`).
6. Не можна **підтвердити порожнє замовлення** (без жодного рядка товару) (`InvalidOperationException`).
7. Не можна **підтвердити замовлення**, якщо воно вже підтверджене або скасоване (`InvalidOperationException`).

## Як запустити
Програма автоматично демонструє два блоки:
1. Імпорт файлів з лабораторної роботи 3.
2. Сценарії доменної моделі (успішне проходження життєвого циклу об'єкта та відловлювання спроб порушити інваріанти).

Усі команди виконуються з кореневого каталогу проєкту.

1. Запуск програми за замовчуванням:
```
dotnet run --project src/Cli
```
1. Явна передача файлу для першої частини програми (імпорт CSV/JSON):
```
dotnet run --project src/Cli -- data/sample.csv
```
