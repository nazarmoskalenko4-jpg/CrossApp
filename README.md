# Лабораторна робота 3: Базові типи домену, Pattern Matching та імпорт

Цей проєкт демонструє використання сучасних можливостей C# (`records`, `nullable` типи, `switch expressions`, `pattern matching`) для моделювання предметної області та надійного імпорту даних.

## Предметна область
Проєкт працює з сутностями **Замовлення** (`OrderDto`) та **Клієнти** (`CustomerDto`). Дані представлені у вигляді незмінних `record`-типів. 

## Формат вхідних даних (CSV)
Програма підтримує імпорт з CSV-файлів, де в одному файлі можуть знаходитись різні типи сутностей (визначаються за префіксом).

- **Кодування:** UTF-8
- **Роздільник:** Крапка з комою (`;`)
- **Заголовок:** Перший рядок має починатися з `type` і автоматично ігнорується парсером.
- **Префікси рядків:**
  - `O` — Замовлення (формат: `O;Id;Назва;Ціна;Примітка(опційно)`)
  - `C` — Клієнт (формат: `C;Id;Ім'я;Телефон`)

Приклад `sample.csv`:
```csv
type;id;name;price_or_phone;note
O;O-001;Ноутбук;1500.50;Термінове замовлення
C;C-001;Іван Москаленко;+380501234567 
```

## Формат вхідних даних (JSON)
Програма також підтримує імпорт замовлень із файлів .json. Парсер обирається автоматично на основі розширення файлу.

## Як запустити
Усі команди виконуються з кореневого каталогу проєкту.

1. Запуск файлу за замовчуванням (data/sample.csv):
```
dotnet run --project src/Cli
```

2. Явна передача правильного шляху до CSV:
```
dotnet run --project src/Cli -- data/sample.csv
```

3. Запуск імпорту JSON:
```
dotnet run --project src/Cli -- data/sample.json
```
4. Демонстрація обробки помилок (неіснуючий файл):
```
dotnet run --project src/Cli -- error.csv
```
